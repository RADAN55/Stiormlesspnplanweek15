# Storm Studio · Week 15 · Soccer: The World's Game

Interactive lesson plans for the EL 9–12 block at Laurel High School, Nov 16–20, 2026.

- **index.html**: interactive lesson-plan magazine. It has a cover, contents, a feature spread for each day (the student text plus the 90-minute plan), an NBCT Component 2 Sample 2 report, a self-grading 10-question quiz, and a flip-card word wall.
- **Week15_EL_Lesson_Plans_Soccer.pdf**: printable lesson plans (8 landscape pages, black-and-white friendly).
- **agenda-board.html**: a daily agenda board for the projector. Each step has a timer, and Friday has the quiz.

Each 90-minute block has three 30-minute segments: Reading, Writing, and ELPA21 Prep. Tasks come in Emerging (ELPA21 1–2) and Progressing (3–4) lanes.
